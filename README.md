# Fellow Stagg EKG Pro (WiFi) for Home Assistant

Home Assistant custom integration for the Fellow Stagg EKG Pro that talks to the
kettle over its local HTTP CLI API (no Bluetooth needed).

The integration and its documentation live in
[`stagg-ekg-plus-ha-addon/`](stagg-ekg-plus-ha-addon/README.md).
